# Play Console answers — data safety and content rating (draft)

Check each answer against the form on the day you submit; Google changes wording from time to time.

## Data safety

| Question | Answer |
|---|---|
| Does the app collect or share user data? | Yes (only for groups) |
| Is all data encrypted in transit? | Yes (Firebase uses HTTPS) |
| Can users ask for their data to be deleted? | Yes: in the app (Profile → Delete my data) and by email |
| Data shared with third parties | None (Firebase is a service provider acting for us, which Play does not count as sharing) |

Data types collected (all **optional**, only when the person starts or joins a group; purpose: **App
functionality**; not used for ads or analytics):

| Category | Type | Notes |
|---|---|---|
| Personal info | Name | Display name chosen for the group |
| Personal info | User IDs | Google or Apple account identifier |
| App activity | Other user-generated content | Group name, purpose, counts, reason if shown, reports |
| Location | Approximate location | Only the city typed for a group; no GPS |

Not collected: email address (unless the person writes to us), phone number, contacts, photos, audio, precise
location, financial info, health info, device or advertising IDs, crash logs (unless you add a crash tool; then
update this form).

## Target audience and content (decided 24 Oct 2026)

| Question | Answer |
|---|---|
| Target age groups | 18 and over only |
| Could the app unintentionally appeal to children? | Answer honestly. If asked, explain: Stories are family content, listened to with a parent; the app is for elders and parents; no child accounts, no ads, no data collected without sign-in. |
| Ads | None |

Keep the store listing consistent with this: "family stories", never "for kids".

## Content rating (IARC questionnaire)

- Violence: none. (Stories are retold gently; no depictions of injury.)
- Fear: none.
- Sexuality, language, drugs, gambling: none.
- User interaction: **yes** — users in groups can see each other's display names, counts and an optional reason;
  no chat, no free messaging, no photos. A report option exists.
- Shares location: no (city only, typed by the organiser).
- Digital purchases: none.
