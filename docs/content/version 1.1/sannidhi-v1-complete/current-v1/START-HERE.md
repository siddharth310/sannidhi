# Sannidhi v1 — start here

Unzip at the repo root (it adds and replaces files; it deletes nothing). Then delete the old
`docs/cursor/P2c*` and `docs/cursor/P2e*` prompts if they are still there.

1. Read `docs/v1/ROADMAP.md` — module order, definition of done, what each module needs from you.
2. Start the critical path today: purohit review, native read, recordings, illustrations, music brief.
   The 108 aṣṭottaram names are in `content/source/ganesha_ashtottara.json`; print
   `content/source/ganesha_ashtottara.md` for the purohit (14 flagged lines to check).
3. In Cursor, paste `docs/cursor/V1-MASTER.md` and write "Run M1." It runs one module, reports, and stops.
   Reply "M1 signed off" to move on: M1 → M2 → M3 → M4 → M5 → (M6) → M7 → M8.
4. Make the audio in your browser: open `tools/sannidhi-audio.ipynb` in Google Colab. For the draft aṣṭottaram,
   do it after M1 step 1 (names imported), and upload the repo's `content/` from then.
5. Release documents (privacy policy, store listing, data safety, checklist) are in `docs/v1/release/`.
   Target audience is decided: adults; Stories are family content.
