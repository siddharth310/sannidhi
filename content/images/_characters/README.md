# Figure library (source drawings, not shipped in the app)

Each god is drawn once here; every scene reuses the same drawing so a god looks the same everywhere.
The `characters` column in `manifest.csv` lists which figures appear in each image.

| Figure | What |
|---|---|
| `chr.ganesha` | The app card (`deity/img.deity.ganesha.card.svg`); four arms, for puja and the god page |
| `chr.ganesha.clay` | The same figure in unpainted clay, for puja steps |
| `chr.ganesha.child` | Two-armed child Gaṇeśa for stories; head identical to the card |
| `chr.ganesha.boy-turmeric` | The boy Pārvatī shaped, before the elephant head |
| `chr.shiva` | Blue-grey skin, jaṭā with crescent and Gaṅgā, serpent, rudrākṣa, tiger skin, triśūla held upright |
| `chr.parvati` | Green sari with gold border, red blouse, kumkum, one hand in blessing |
| `chr.kartikeya` | Young boy, small crown, vel held upright |
| `chr.narada` | Sage in white with a saffron upper cloth, tambura |
| `chr.mushika`, `chr.peacock`, `chr.chandra` | Gaṇeśa's mouse, Kārtikeya's peacock, the moon |
