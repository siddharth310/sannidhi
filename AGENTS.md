# Rules for coding agents (Cursor)

Android app, Kotlin + Jetpack Compose. Working name **Sannidhi** (earlier Naamalu / Smaranam).
Read these before writing code, in this order:

1. `docs/app-flow.md` — what screens exist and how they connect (v6).
2. `docs/design-v6.md` — how each screen looks.
3. `docs/content-architecture.md` — where content comes from.
4. `app/src/main/java/app/sannidhi/content/` — the Kotlin content contract (models + repository).
5. The phase prompt you were given from `docs/cursor/`.

## Hard rules

1. **Content is data, never code.** All text, mantras, names, dates, images come from
   `app/src/main/assets/content/` through `ContentRepository`. Never hard-code a deity, festival, mantra, name,
   story line or date in Kotlin. Never edit files under `assets/content/` — they are generated by
   `tools/build_content.py`. If a screen needs a field that isn't in `content/_schema/`, stop and say so.
2. **Never write or change sacred text** (mantras, divine names, stories, rāśi notes). Not even "fixing" spelling.
3. **No bottom navigation.** Home is the hub. Every inner screen uses the shared `TopBar` with Back and Home.
4. **Free will, not tasks.** No reminders, notifications, streaks, "0 today", "not done", red states or progress
   gaps anywhere in practice. See the word list in `docs/design-v6.md` §11.
5. **No fear.** The rāśi note is shown for today only, exactly as written in `rashi.json`.
6. **Elder-first.** Touch targets ≥ 56 dp, body ≥ 16 sp (18 sp default), labels in script + English where the
   spec says so, no gestures without a visible button alternative.
7. **Privacy.** Guest-first. No OTP, phone number, email, GPS, contacts or photos. Practice data stays in Room on
   the phone. Firebase only for groups (Phase 5) and only after Google sign-in.
8. **Puja logs nothing.** Only Sankalpam writes `PracticeEntry`.
9. Missing image → fallback per `docs/design-v6.md` §10. Never a broken or grey box.
10. Debug builds show a small "draft" chip on draft content; release builds contain no drafts.

## Stack

Compose + Material 3 (custom theme), Navigation-Compose (type-safe routes), kotlinx.serialization, Room,
DataStore (preferences), Media3 ExoPlayer (Listen), Coil (assets, WebP). Min SDK 26. One activity.

Package: the reference files use `app.sannidhi`. If the project already has a different base package, move the
files under it and fix the `package` lines — **do not change `applicationId`** once it has shipped.

## Layout

```

  content/       ContentModels.kt, ContentRepository.kt, Labels.kt      (contract — change only with the schema)
  practice/      PracticeModels.kt (Room entities), dao, repository
  settings/      DataStore: lang, textView, state, city, name, rashi, nakshatra, gotra, onboarded
  ui/theme/      Color.kt, Type.kt, Theme.kt, Shapes.kt
  ui/common/     TopBar, ModuleCard, ComingUpCard, SacredText, LangChips, ImageOrFallback, StageBar
  ui/home/  ui/puja/  ui/calendar/  ui/sankalpam/  ui/stories/  ui/onboarding/  ui/profile/
```

## Definition of done for any task

- Builds with no warnings you introduced; no hard-coded content strings (UI chrome strings go in
  `res/values{,-te,-hi}/strings.xml`).
- Works in te, hi and en; works at 200% font scale; works offline.
- The phase prompt's acceptance checks pass. Report each one as pass / fail in your final message.
